# แปลงไฟล์ทุกแบบ (File Converter)

เว็บแอปแปลง/จัดการไฟล์ PDF, Excel, Word และรูปภาพ — **ทำงานทั้งหมดในเบราว์เซอร์ของผู้ใช้เอง** ไม่มี backend ไม่มีเซิร์ฟเวอร์ ไม่มีการอัปโหลดไฟล์ไปที่ไหนทั้งสิ้น เปิดเป็นไฟล์ static (HTML/CSS/JS) ล้วนๆ ไม่ต้อง build ไม่ต้อง `npm install`

---

## 1. เครื่องมือทั้งหมด (13 ตัว)

| หมวด | เครื่องมือ | ทำอะไร |
|---|---|---|
| จัดการไฟล์ PDF | จัดการหน้า PDF | เลือกเก็บ/ลบหน้า, ลากสลับลำดับ, หมุนหน้า, ส่งออกเป็น PDF ใหม่ |
| | รวมไฟล์ PDF | รวมหลายไฟล์เป็นไฟล์เดียว |
| | แยกไฟล์ PDF | แยกตามหน้า/ช่วงหน้าที่กำหนด |
| | บีบอัดไฟล์ PDF | ลดขนาดไฟล์ (rasterize เป็นภาพคุณภาพที่เลือกได้) |
| | OCR อ่านข้อความจากภาพสแกน | อ่านตัวอักษรในภาพ → PDF ที่ค้นหาได้ หรือ .txt |
| แปลงจาก PDF | PDF → รูปภาพ | ทุกหน้า/บางหน้า เป็น PNG หรือ JPG |
| | PDF → ข้อความ | ดึงข้อความเป็น .txt |
| | PDF → Word | เป็นเอกสาร .docx |
| | PDF → Excel | จับตำแหน่งคอลัมน์ในตาราง แปลงเป็น .xlsx |
| แปลงเป็น PDF | Word → PDF | .docx → PDF (รักษาหัวข้อ/ย่อหน้า/รายการ/ตาราง/รูป) |
| | Excel → PDF | แต่ละชีทกลายเป็นตารางในหน้าใหม่ |
| | รูปภาพ → PDF | รวมรูปหลายไฟล์เป็น PDF เดียว |
| รูปภาพ | แปลงชนิดไฟล์รูปภาพ | สลับ PNG / JPG / WEBP / BMP |

## 2. ขั้นตอนที่ทำ (ลำดับการพัฒนา)

1. **โครงพื้นฐาน** — `index.html` + `css/style.css` (ธีม light/dark) + `js/utils.js` (helper กลาง เช่น อ่านไฟล์, ดาวน์โหลด blob, zip หลายไฟล์) + `js/dropzone.js` (คอมโพเนนต์ลากไฟล์วาง ใช้ร่วมกันทุกเครื่องมือ) + `js/main.js` (เมนู/นำทางระหว่างเครื่องมือ)
2. **เครื่องมือจัดการ PDF พื้นฐาน** — จัดการหน้า (`pageManager.js`), รวมไฟล์ (`pdfMerge.js`), แยกไฟล์ (`pdfSplit.js`) โดยใช้ pdf.js สร้างภาพตัวอย่างหน้า และ pdf-lib จัดการหน้าจริง
3. **แปลงจาก PDF** — รูปภาพ, ข้อความ, Word, Excel โดยเขียน heuristic เอง (`js/tableExtract.js`) เพื่อจับตำแหน่งคอลัมน์ตารางจากพิกัด x/y ของตัวอักษรใน PDF (pdf.js ให้แค่ข้อความเรียงตามลำดับ ไม่ได้บอกว่าอะไรอยู่คอลัมน์ไหน)
4. **เครื่องมือรูปภาพ** — รูปภาพ→PDF, แปลงชนิดไฟล์ (เขียน BMP encoder เองใน `js/bmpEncoder.js` เพราะเบราว์เซอร์ไม่มี API เข้ารหัส BMP ให้)
5. **แปลงเป็น PDF (รอบเพิ่มเติม)** — Word→PDF, Excel→PDF โดยต้องแก้ปัญหาฟอนต์ไทยก่อน (ดู `js/thaiFont.js`) เพราะฟอนต์ในตัวของ jsPDF ไม่รองรับอักษรไทย
6. **บีบอัด PDF + OCR (รอบเพิ่มเติม)** — บีบอัดด้วยการ rasterize หน้าเป็นภาพคุณภาพต่ำลง, OCR ด้วย Tesseract.js พร้อมสร้าง "PDF ที่ค้นหาได้" (ภาพเดิม + ชั้นข้อความล่องหนทับ)
7. **ทดสอบ end-to-end ทุกเครื่องมือ** ผ่านเบราว์เซอร์อัตโนมัติด้วยไฟล์ทดสอบจริง (สร้าง .docx/.xlsx/PDF สแกนจำลองขึ้นมาเอง) ตรวจสอบเนื้อหาไฟล์ผลลัพธ์จริง ไม่ใช่แค่ข้อความ "สำเร็จ" — ระหว่างทางเจอและแก้บั๊ก 3 จุด:
   - การจับคอลัมน์ตารางใน PDF→Excel รวมทุกคอลัมน์เป็นช่องเดียว (ต้นเหตุ: ช่องว่างระหว่างคอลัมน์ถูกเก็บเป็น item พิเศษของ pdf.js ที่มี width ครอบคลุมทั้งช่องว่าง ทำให้ตรวจจับช่องว่างจริงไม่ได้)
   - หัวข้อตัวหนาภาษาไทยใน PDF ที่สร้างขึ้นเพี้ยนเป็นตัวอักษรมั่ว (ต้นเหตุ: ไม่ได้ลงทะเบียนฟอนต์ไทยในสไตล์ "bold" ทำให้ jsPDF สลับไปใช้ฟอนต์ default ที่ไม่รองรับไทย)
   - ชั้นข้อความ OCR แยกเป็นตัวอักษรเดี่ยวๆ (ต้นเหตุ: ภาษาไทยไม่มีช่องว่างระหว่างคำ ทำให้ Tesseract ตัดคำเป็นชิ้นเล็กมาก) และหน้ากระดาษแนวนอนจาก OCR ขนาดสลับกัน (ต้นเหตุ: jsPDF ปรับขนาดหน้าที่กำหนดเองให้เข้ากับแนวตั้งเสมอถ้าไม่ระบุ orientation)

## 3. Library ที่ใช้ (ทั้งหมดโหลดผ่าน CDN ไม่มีใน `node_modules`)

| Library | เวอร์ชัน | ใช้ทำอะไร |
|---|---|---|
| [pdf.js](https://mozilla.github.io/pdf.js/) | 3.11.174 | อ่าน/แสดงผลหน้า PDF, ดึงข้อความพร้อมพิกัด x/y (ใช้เป็นฐานของแทบทุกเครื่องมือที่รับ PDF เป็น input) |
| [pdf-lib](https://pdf-lib.js.org/) | 1.17.1 | สร้าง/แก้ไข/รวม/แยก PDF, ฝังรูปภาพลง PDF (ใช้ในจัดการหน้า, รวม, แยก, รูปภาพ→PDF, บีบอัด) |
| [SheetJS (xlsx)](https://sheetjs.com/) | 0.18.5 | อ่าน/เขียนไฟล์ Excel (.xlsx) |
| [docx](https://docx.js.org/) | 8.5.0 | สร้างไฟล์ Word (.docx) — ใช้ใน PDF→Word |
| [JSZip](https://stuk.github.io/jszip/) | 3.10.1 | รวมหลายไฟล์ผลลัพธ์เป็น .zip เดียว (เช่น แยกหน้า PDF, PDF→รูปภาพหลายหน้า) |
| [mammoth.js](https://github.com/mwilliamson/mammoth.js) | 1.8.0 | อ่านเนื้อหาไฟล์ Word (.docx → HTML) — ใช้ใน Word→PDF |
| [jsPDF](https://github.com/parallax/jsPDF) | 2.5.1 | สร้างไฟล์ PDF จากศูนย์ — ใช้ใน Word→PDF, Excel→PDF, OCR (searchable PDF) |
| [jspdf-autotable](https://github.com/simonbengtsson/jsPDF-AutoTable) | 3.8.2 | plugin ของ jsPDF สำหรับวาดตารางที่จัดหน้า/แบ่งหน้าอัตโนมัติ |
| [Tesseract.js](https://tesseract.projectnaptha.com/) | 5.1.1 | OCR อ่านตัวอักษรจากภาพ ทำงานในเบราว์เซอร์ล้วนๆ (WebAssembly) รองรับไทย+อังกฤษ |
| [Noto Sans Thai](https://fonts.google.com/noto/specimen/Noto+Sans+Thai) (ผ่าน jsDelivr mirror ของ repo `google/fonts`) | — | ฟอนต์ที่ฝังเข้า jsPDF เพื่อให้วาด/อ่านข้อความภาษาไทยได้ (ฟอนต์มาตรฐานของ jsPDF รองรับแค่ภาษาอังกฤษ) |

**โค้ดที่เขียนเองทั้งหมด (ไม่มี library สำเร็จรูป):**
- `js/tableExtract.js` — จับตำแหน่งคอลัมน์ตารางจากพิกัดตัวอักษรใน PDF (heuristic แบบ cluster ตามแนวตั้ง/แนวนอน)
- `js/bmpEncoder.js` — เขียนไฟล์ BMP 24-bit เองจาก canvas เพราะเบราว์เซอร์ไม่มี API เข้ารหัส BMP
- `js/thaiFont.js` — โหลดและลงทะเบียนฟอนต์ไทยให้ jsPDF
- `js/pageRange.js` — แปลงข้อความช่วงหน้า (เช่น `1-3,5,7-9`) เป็นรายการเลขหน้า

## 4. คู่มือผู้ใช้ (User Guide)

ทุกเครื่องมือใช้ขั้นตอนเดียวกัน:

1. เปิดหน้าเว็บ → คลิกการ์ดเครื่องมือที่ต้องการจากหน้าแรก
2. **อัปโหลดไฟล์** — คลิกที่กล่องเพื่อเลือกไฟล์ หรือลากไฟล์มาวาง
3. ปรับ **ตัวเลือก** ตามต้องการ (เช่น รูปแบบไฟล์, คุณภาพ, ช่วงหน้า) — แต่ละเครื่องมือมีค่าเริ่มต้นที่ใช้งานได้เลยโดยไม่ต้องปรับ
4. กดปุ่มแปลง/ประมวลผล รอสถานะขึ้น "สำเร็จ" (แถบสีเขียว)
5. ไฟล์จะถูก **ดาวน์โหลดอัตโนมัติ** ไปยังโฟลเดอร์ดาวน์โหลดของเบราว์เซอร์ (ถ้าได้หลายไฟล์ ระบบจะรวมเป็น .zip ให้)
6. กด "← กลับหน้าหลัก" มุมขวาบนเพื่อเลือกเครื่องมืออื่น

### เฉพาะทาง — จัดการหน้า PDF
อัปโหลดแล้วจะเห็นภาพตัวอย่างทุกหน้า: ลากการ์ดเพื่อสลับลำดับ, กดไอคอนถังขยะเพื่อลบหน้านั้น (กดซ้ำเพื่อกู้คืน), กดไอคอนหมุนซ้าย/ขวาเพื่อหมุนหน้านั้น, ใช้แถบปุ่มด้านบน (เลือกทั้งหมด/ไม่เลือกทั้งหมด/สลับการเลือก) เพื่อจัดการหลายหน้าพร้อมกัน แล้วกด "ส่งออกเป็น PDF ใหม่"

### เฉพาะทาง — OCR
ใช้กับ PDF ที่เป็น**ภาพสแกน** (คัดลอกข้อความไม่ได้) เท่านั้น — ถ้า PDF คัดลอกข้อความได้อยู่แล้ว ให้ใช้เครื่องมือ PDF→Word/Excel/ข้อความแทนโดยตรง จะเร็วและแม่นยำกว่า เลือกภาษาในเอกสาร (ไทย+อังกฤษ/ไทย/อังกฤษ) และรูปแบบผลลัพธ์ (PDF ที่ค้นหาได้ หรือ .txt) — OCR ใช้เวลานานกว่าปกติเพราะต้องอ่านตัวอักษรทีละหน้า และครั้งแรกอาจโหลดข้อมูลภาษาเพิ่มเติมจากอินเทอร์เน็ต

### ข้อจำกัดที่ควรรู้
- PDF→Word/Excel/ข้อความ ใช้ไม่ได้กับ PDF ภาพสแกน (ต้องใช้ OCR แทน)
- การจับตารางใน PDF→Excel เป็นการประมาณ ควรตรวจสอบผลลัพธ์กับตารางที่ซับซ้อนมาก
- Word→PDF แปลงแบบข้อความ (โครงสร้างหลักคงไว้) ไม่ใช่ pixel-perfect กับต้นฉบับทุกจุด
- บีบอัด PDF ทำให้ข้อความในไฟล์กลายเป็นภาพ **คัดลอก/ค้นหาไม่ได้อีก** — ใช้เมื่อต้องการไฟล์เล็กมากกว่าคุณภาพ/ฟีเจอร์นี้

## 5. คู่มือฝั่งรัน/ดูแล (สำหรับคุณ)

### รันตอน dev
ต้องรันผ่าน **local web server** เท่านั้น (เปิดไฟล์ `index.html` ตรงๆ แบบ `file://` จะไม่ทำงาน เพราะโค้ดใช้ ES Modules ซึ่งเบราว์เซอร์บล็อกการโหลดข้าม `file://`)

```bash
cd convert
python -m http.server 8791
```

แล้วเปิด `http://localhost:8791` — ไม่ต้อง `npm install` เพราะทุก library โหลดจาก CDN ตรงในหน้าเว็บ

ทางเลือกอื่นแทน Python ก็ได้เหมือนกัน เช่น:
```bash
npx serve .
```

### โครงสร้างไฟล์
```
convert/
├── index.html          # โครงหน้าเว็บ + CDN script tags ทั้งหมด
├── css/style.css        # ธีม (รองรับ light/dark)
├── js/
│   ├── main.js           # เมนู/นำทางระหว่างเครื่องมือ
│   ├── utils.js           # helper กลาง (อ่านไฟล์, ดาวน์โหลด, zip, render PDF)
│   ├── dropzone.js        # คอมโพเนนต์ลากไฟล์วาง
│   ├── pageRange.js        # แปลง "1-3,5" เป็นรายการเลขหน้า
│   ├── tableExtract.js      # จับคอลัมน์ตารางจาก PDF
│   ├── bmpEncoder.js        # เขียนไฟล์ BMP เอง
│   ├── thaiFont.js          # โหลด/ลงทะเบียนฟอนต์ไทยให้ jsPDF
│   └── tools/              # เครื่องมือแต่ละตัว (1 ไฟล์ต่อ 1 เครื่องมือ)
└── .claude/launch.json    # ตั้งค่า preview server (ใช้ตอน dev ผ่าน Claude Code)
```

### แก้ไข/เพิ่มเครื่องมือใหม่
ทุกไฟล์ใน `js/tools/*.js` มีรูปแบบเดียวกัน: export ฟังก์ชัน `mount(container)` ที่สร้าง UI และ logic ของเครื่องมือนั้น แล้วไปลงทะเบียนใน `TOOLS` array ที่ [js/main.js](js/main.js) (มี `id`, `icon`, `title`, `desc`, `mod` เป็น path ไปยังไฟล์เครื่องมือ)

## 6. Deploy ขึ้น GitHub ได้ไหม?

**ได้ และเหมาะมากด้วย** — เพราะแอปนี้เป็น static site ล้วนๆ (ไม่มี backend, ไม่มี build step, ไม่มี environment variable ลับ) จึงใช้ **GitHub Pages** โฮสต์ฟรีได้ตรงๆ โดยไม่ต้องเปลี่ยนโค้ดอะไรเลย

### ขั้นตอน
1. สร้าง repository บน GitHub (public หรือ private ก็ได้ — repo private ใช้ GitHub Pages ได้เฉพาะแพลน paid)
2. ในโฟลเดอร์โปรเจกต์:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```
3. ไปที่ repo บน GitHub → **Settings → Pages**
4. ที่ **Source** เลือก **Deploy from a branch** → Branch เลือก `main` และโฟลเดอร์ `/ (root)` → กด **Save**
5. รอสัก 1-2 นาที จะได้ลิงก์ประมาณ `https://<username>.github.io/<repo>/`

### สิ่งที่ควรรู้ก่อน deploy
- **ผู้ใช้ปลายทางยังต้องออนไลน์** ตอนใช้งาน เพราะ library ทั้งหมดโหลดจาก CDN (pdf.js, pdf-lib, Tesseract.js ฯลฯ) — ตัวเว็บเองอยู่บน GitHub Pages แต่ dependency ยังดึงจากอินเทอร์เน็ตทุกครั้งที่เปิดหน้า
- ความเป็นส่วนตัวไม่เปลี่ยนไป — ไฟล์ของผู้ใช้ยังประมวลผลในเบราว์เซอร์เขาเองทั้งหมด GitHub Pages แค่เสิร์ฟไฟล์ HTML/CSS/JS เท่านั้น ไม่เห็นไฟล์ที่ผู้ใช้อัปโหลด
- ถ้าอยากได้โดเมนของตัวเอง ตั้งค่า custom domain เพิ่มได้ที่หน้า Settings → Pages เช่นกัน (เพิ่มไฟล์ `CNAME` หรือกรอกในช่อง)
- ไม่ต้องมี GitHub Actions/build pipeline ใดๆ เพราะไม่มีขั้นตอน build — push ไฟล์ตรงๆ ก็ใช้งานได้เลย

อยากให้ผมช่วย `git init` + commit แรกให้ในเครื่องนี้เลยไหมครับ (ไม่ push ไปไหนจนกว่าจะให้ไป)? หรือถ้ามี repo บน GitHub อยู่แล้วบอกชื่อมาได้เลย
